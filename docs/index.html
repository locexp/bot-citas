SuperBot

Descarga el título, la descripción, el precio y las imágenes de productos de supermercados online. Desde el móvil, por Telegram o desde la línea de comandos.

Abrir la app Código en GitHub

Qué hace

🔗 Productos o categorías

Pega el enlace de un producto, o el de una categoría u oferta para bajarlos todos.

📦 ZIP, CSV y JSON

Imágenes en carpetas por producto y una tabla que se abre en Excel.

📱 Pensado para el móvil

App web que se añade a la pantalla de inicio, o bot de Telegram.

🤝 Uso responsable

Respeta robots.txt, espera entre peticiones y avisa si una web lo bloquea.

Cómo empezar

Importante: esta página (GitHub Pages) solo aloja la interfaz. El bot que descarga los datos tiene que estar funcionando en tu móvil, tu PC o un servidor. La primera vez que abras la app, pulsa ⚙ Servidor y escribe su dirección.

📱 En el móvil Android (Termux)
  1. Instala Termux desde F-Droid.
  2. En Termux: 
    pkg install -y git
git clone https://github.com/locexp/bot-citas.git
cd bot-citas
./iniciar.sh
  3. Abre la app en Chrome. Se conectará a http://localhost:8000. También puedes abrir esa dirección directamente.
✈️ Por Telegram
  1. En Telegram, abre @BotFather → /newbot y copia el token.
  2. En el ordenador o en Termux: 
    git clone https://github.com/locexp/bot-citas.git
cd bot-citas
cp .env.ejemplo .env      # pega el token en TELEGRAM_TOKEN
./iniciar.sh telegram
  3. Escríbele /yo a tu bot y pon ese número en TELEGRAM_USUARIOS para que solo tú puedas usarlo.
  4. Envíale un enlace de producto, o /categoria <enlace>.
💻 En tu PC (y usarlo desde el móvil) 
  1. git clone https://github.com/locexp/bot-citas.git
cd bot-citas
pip install -r requirements.txt
python app.py
  2. Abre en el móvil la dirección que aparece (por ejemplo http://192.168.1.20:8000), con el móvil en la misma wifi.
☁️ En un servidor (Render, Railway, VPS…)
  1. Despliega el repositorio con el comando de inicio python app.py y pon la variable BOT_CLAVE con una clave.
  2. En la app, pulsa ⚙ Servidor y escribe la dirección https://… del servidor.
  3. Ojo: muchas tiendas bloquean las conexiones de servidores en la nube. Desde casa o el móvil suele ir mejor.
